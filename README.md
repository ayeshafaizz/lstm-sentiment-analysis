# LSTM Sentiment Analysis

## Overview

This project performs sentiment analysis on the IMDB Movie Reviews dataset using deep learning models. It builds and compares **Bidirectional LSTM (BiLSTM)** and **GRU** networks for binary sentiment classification.

## Features

* Loads and preprocesses the IMDB dataset
* Implements a Bidirectional LSTM model
* Implements a GRU model
* Trains and evaluates both models
* Compares model performance using accuracy and loss metrics
* Visualizes training results with plots
* Displays misclassified reviews for analysis

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Matplotlib

## Results

Both BiLSTM and GRU models are trained on the IMDB dataset and evaluated on test data. Performance is compared through accuracy, loss, and learning curves.

## Project Structure

* Data Loading & Preprocessing
* BiLSTM Model Training
* GRU Model Training
* Model Evaluation
* Performance Comparison
* Visualization & Analysis
